CAREER PLATFORM COMPLETE CLEAN BUNDLE

This bundle uses a NEW database: career_platform_complete.db. It will not modify older project databases.

Features: student registration/login, profile, jobs, applications, admin job management, career suggestions, skill gap, skills to learn, low-priority skills, learning roadmap, first project, and future career outlook.
Career suggestions are rule-based guidance, not a trained AI model.

WINDOWS RUN:
1. Extract this ZIP into a new folder.
2. Open the folder in File Explorer.
3. Click the address bar, type cmd, press Enter.
4. Run: python -m pip install -r requirements.txt
5. Run: python -m streamlit run app.py

ADMIN PASSWORD:
Create a folder named .streamlit and a file named secrets.toml inside it.
Put this line in secrets.toml:
ADMIN_PASSWORD = "your-own-password"
Use a password you choose and keep it private.
